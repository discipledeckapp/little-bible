# Little Bible agent instructions

For Bible content work, use the project skills in `.agents/skills/`.

- Coordinate with `$little-bible-content-workflow`.
- Draft with `$little-bible-content-writer`.
- Review theology with `$little-bible-theology-review`.
- Review child learning and safety with `$little-bible-child-review`.
- Publish and track with `$little-bible-record-keeper`.

`docs/LittleBible_Content_Standard_v2.md` Standard 2.1 or later controls where older documentation conflicts. Role write boundaries and workflow claims are mandatory for concurrent work.
